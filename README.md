לומדה אינטראקטיבית: מניעה וטיפול בפצעי לחץ
לומדה אינטראקטיבית בעברית, המיועדת לצוותים רפואיים ובפרט לאחיות ולאחים. הלומדה משלבת הסברים, תרחישים ושאלות לתרגול בנושאי פצעי לחץ.
נושאי הלומדה
- מנגנון היווצרות פצעי לחץ וגורמי סיכון
- סיווג פצעי לחץ בשלבים 1–4, פצע שאינו ניתן לסיווג ופגיעה ברקמות עמוקות
- מניעה: הערכת סיכון, בדיקת העור, שינויי תנוחה, פריקת לחץ מהעקבים, לחות ותזונה
- פגיעות הקשורות להתקנים רפואיים
- הערכת הפצע, תיעוד, טיפול והפניה לייעוץ מקצועי
- תרגול באמצעות שאלות ומקרים קליניים
הפעלה
הלומדה היא אתר סטטי המבוסס על HTML, CSS ו‑JavaScript. אין צורך להתקין תוכנה או לבנות את הפרויקט.
פרסום ב‑GitHub Pages
1. העלו את תוכן התיקייה הזו למאגר GitHub.
2. ודאו שהקובץ index.html נמצא בתיקיית השורש של המאגר, ושומרים על מבנה התיקיות והקבצים.
3. במאגר בחרו Settings → Pages.
4. תחת Build and deployment, בחרו Deploy from a branch, את הענף main ואת התיקייה /(root), ולחצו Save.
5. לאחר השלמת הפרסום, GitHub יציג את כתובת הלומדה בחלק העליון של עמוד Pages.
אפשר לפתוח את index.html בדפדפן גם ללא פרסום. להפעלה מקומית, יש להשאיר את קובצי המדיה והתיקיות לצד הקובץ ולשמור על המבנה המקורי.
מבנה הקבצים
- index.html — נקודת הכניסה ללומדה
- src/ — קוד הלומדה והנתונים
- styles/ — עיצוב ותצוגה
- scenes/ — תמונות ותוכן לפי פרקי הלומדה
- shared/ — קובצי מדיה משותפים, כולל קריינות ואיורים
נגישות ותצוגה
הלומדה בעברית ובכיווניות מימין לשמאל, מותאמת למסכים שונים, וכוללת תצוגה אופקית ייעודית לטלפונים. מומלץ להשתמש בדפדפן עדכני.
קרדיט
פיתוח הלומדה והעריכה המקצועית: אליהו קוסמן, רוקח קליני.

חלק מהתמונות, האיורים והקריינות הופקו או עובדו בסיוע כלי בינה מלאכותית. יש להתייחס לתוכן הלומדה כחומר לימודי; הוא אינו מחליף שיקול דעת קליני, נהלים מקומיים או ייעוץ של גורם מקצועי מוסמך.
